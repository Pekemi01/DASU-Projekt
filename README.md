# DASU-Projekt

README zum WIF-Projekt des DASU-Teams

### Wichtig bei Web-App Commits & Push
- node_modules & .next Ordner löschen -> Dateien viel zu groß
- dann folgende Commands im Terminal (VS Code, cmd o.Ä.) ausführen:
  - cd ...\my-app (Ordner in dem package.json liegt)
  - npm install next react react-dom
  - npm run dev
- danach sollte localhost:3000 erreichbar sein
